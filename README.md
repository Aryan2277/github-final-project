# # Simple Interest Calculator

A simple Bash script designed to calculate simple interest given the principal amount, annual interest rate, and time period in years.

## Description
This script takes three inputs:
- **Principal Amount** ($P$)
- **Rate of Interest per annum** ($R$)
- **Time Period in years** ($T$)

It calculates the Simple Interest using the standard formula:
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

## Usage
Run the script in a bash shell:
```bash
bash simple-interest.sh
